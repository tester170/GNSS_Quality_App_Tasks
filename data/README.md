# Данные к практической работе: контроль качества RTK-решений

Источник: таблица эпох SmartPNT-POS, сформированная в блокноте курса:
https://colab.research.google.com/drive/11Y1cc4qv-j1Gm9AWDov47GBf6HwEQQrN

Исходный открытый набор: https://www.kaggle.com/datasets/fengzhusgg/smartpnt-pos

В таблицах только FIX-решения RTKLIB после синхронизации и контроля опорной траектории.
Из исходных 158 706 эпох отобрано 56 793. Значения признаков и координат не изменены.

- rtk_development.csv: обучение — S01 и S03 (52 445 эпох), валидация — S04 (3 103 эпохи).
- rtk_test.csv: итоговая проверка — S02, маршрут DATA02 (1 245 эпох).
- subset: назначение строки, не входной признак.
- fixed_error_h: горизонтальное расхождение с опорной траекторией, м; только разметка и оценка.
- Целевой класс: 1 при fixed_error_h > 0.30, иначе 0.

Соседние эпохи и кампании одной пространственной группы не распределены по разным выборкам.
Разделение назначено до сравнения моделей и не подбирается по их результатам.
На тестовой группе всего 5 превышений допуска: один пропуск изменяет полноту на 20 процентных пунктов.
Это учебная проверка, а не подтверждение производственной надёжности. Все группы уже рассматривались в курсе.
Демонстрационный rtk_demo.csv из приложения относится к DATA13 (обучающая группа S01):
его нельзя использовать для независимой оценки новой модели.
