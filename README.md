# Самостоятельная работа: контроль качества RTK-решений

Обучите несколько моделей, проведите один собственный эксперимент и примените выбранную модель
в [GNSS_Quality_App](https://github.com/Alexandre77777/GNSS_Quality_App).

## Как выполнить работу

1. Откройте `GNSS_Задание.ipynb` в Google Colab и сохраните копию на своём Google Диске.
2. Последовательно выполняйте задания. Ячейка 2.1 сама загрузит входные CSV из папки `data`.
3. Выберите один эксперимент: изменить набор признаков или глубину дерева.
4. Сохраните модель и следуйте инструкции по её замене в приложении.

GPU не нужен. Технические функции даны готовыми; самостоятельно выполняются осмотр данных,
выбор изменения, сравнение результатов и выводы. Результат не обязан превосходить исходную модель.
